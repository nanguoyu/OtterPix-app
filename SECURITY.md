# Security policy

中文用户：安全问题请通过下述私密渠道报告。 · Deutschsprachige: Sicherheitsprobleme bitte vertraulich melden.

## Scope

This policy covers the **OtterPix Mac app** (distributed through the Mac App Store) and the website **otterpix.app**.

## How to report

Please report vulnerabilities **privately** — do not open a public issue for a security report.

- **Preferred:** GitHub Private Vulnerability Reporting — on this repository, open the **Security** tab and choose **Report a vulnerability**.
- **Email:** hello@otterpix.app

Include what you found, where, and steps to reproduce. Reports in English, 中文, or Deutsch are all fine.

## What to expect

- Acknowledgment within **5 business days**.
- A fix ships through the Mac App Store as fast as App Review allows; you'll be told when it's out.
- If you'd like credit for the find, say so — happy to acknowledge you in the release notes.
