# 元数据

**元数据**——App Store 商品页上称“EXIF 查看器”——读取、编辑并清除照片里的隐藏数据：EXIF 相机参数、GPS 坐标、IPTC 创作者字段和文件详情。它最常干的活只需一个开关：在照片离开你的 Mac 之前去掉 GPS 位置。

## 一览

| | |
|---|---|
| **可用性** | 免费 |
| **运行方式** | 在你的 Mac 上——离线运行，不上传任何内容 |
| **输入** | 一张或多张图片（多张时出现缩略图条） |
| **输出** | 清理/编辑后的副本保存到你选择的位置；原文件不受影响 |
| **流水线步骤** | **清除元数据**——见[流水线](../pipeline.md) |

## 三种模式

工具顶部有三种模式：**查看**、**编辑**和**清除**。

### 查看

文件携带的一切，分组整齐呈现：相机（品牌、型号、镜头）、EXIF 曝光数据（光圈、快门速度、ISO、焦距、拍摄日期）、GPS（纬度、经度、海拔）、IPTC（创作者、来源、说明、版权）以及文件详情（尺寸、色彩模型、方向、软件）。

### 编辑

逐项改写字段——**作者**、**版权**、**描述**、**拍摄日期**——或打开**移除 GPS** 开关：只去掉位置，相机、日期和曝光字段全部保留。用**保存修改…**（⌘S）提交。

### 清除

通过**预设**选择整体清除的力度，然后**清除并另存为…**：

- **隐私** — “清除 GPS、相机型号、镜头、创作者。保留拍摄日期、曝光数据、方向。”它还会移除相机所有者姓名和镜头序列号，以及 IPTC 中的创作者、联系方式、版权和地点字段。分享前的合理默认：照片仍能按日期正确排序、方向正常显示，但不再暴露在哪里、用什么设备、由谁拍的。
- **全部** — “清除所有元数据字段。仅保留像素数据。”

## 分享前如何去掉 GPS

1. 点击侧边栏的**全部功能**，再点**元数据**。
2. 拖入一张或几张照片——多个文件时底部出现缩略图条，可以逐张翻看。
3. 先在**查看**模式确认文件里到底有什么。
4. 只去位置：切到**编辑**，打开**移除 GPS**，按**保存修改…**（⌘S）。
5. 想清得更干净：切到**清除**，选**隐私**或**全部**预设，点击**清除并另存为…**。
6. 选择清理后副本的保存位置。磁盘上的原文件保持不变。

## 为什么要清除元数据

照片的 EXIF 可能包含拍摄地点的精确 GPS 坐标——发布之前值得主动去掉，因为电子邮件、网盘和直接上传文件通常会原封不动地把原文件传出去。

## 提示与限制

- **清除元数据不改变画面。** 操作只针对那些隐藏的记录，不动可见的画面；JPEG 等有损格式会以高质量重新编码。清理结果保存为新副本，随时可以对比两个版本。
- **整个文件夹：** 在[流水线](../pipeline.md)里加一个**清除元数据**步骤，一次跑完一个文件夹——愿意的话缩放、加水印也在同一趟。
- **别指望平台替你清除。** 很多社交网络会重新处理上传图片并丢掉大部分元数据，但细节因平台而异、随时间变化。真在乎的话，就把清除做成一个明确的步骤。

## 疑难解答

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 查看模式里 GPS 区是空的 | 照片本来就没有位置数据（或早已被清除） | 没什么可清的——已经完成 |
| 编辑过的字段没生效 | 修改在保存时写入，不是实时写入 | 按**保存修改…**（⌘S），并检查保存出的副本 |
| 清除后按日期排序乱了 | **全部**预设连拍摄日期一起清掉了 | 改用**隐私**预设——它保留日期、曝光和方向 |
| 还是解决不了 | — | [提交 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
