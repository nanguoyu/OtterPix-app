# 调整大小、裁剪与图片旋转

几何三件套：**调整大小**按百分比或精确尺寸缩放图片，**裁剪**以自由或固定纵横比裁切画面，**图片旋转**支持任意角度旋转和翻转。三个工具都免费，也都有对应的[流水线](../pipeline.md)步骤可以批量使用。

## 一览

| | |
|---|---|
| **可用性** | 免费 |
| **运行方式** | 在你的 Mac 上——离线运行，不上传任何内容 |
| **输入** | 单张图片或整批 |
| **输出** | 处理后的副本，保存到你选择的位置 |
| **流水线步骤** | **缩放**、**裁剪**、**旋转**——见[流水线](../pipeline.md) |

## 调整大小

1. 点击**调整大小**，拖入图片。
2. 选择缩放方式：按百分比，或在**宽度**和**高度**栏输入精确像素值。数值可以直接键入，也可以用旁边的步进按钮微调。
3. 两个输入框之间的锁链图标切换**锁定纵横比**——锁定时改一个值另一个自动换算；解锁后两个值各自独立（图片可能被拉伸变形）。
4. 按**保存**（⌘S）。

### 选项

- **按百分比** — 快速等比缩放，例如网页用图缩到 50%。
- **精确尺寸** — 以像素为单位输入**宽度** / **高度**，**锁定纵横比**默认开启。
- **限定在** — 批量友好的“包围盒”模式。用应用自己的话说：“每张图按自身比例缩放以适应此框；已小于该尺寸的图保持不变。”当一个文件夹里竖图横图混在一起、又都不能超过比如 1920 px 时，这个模式最合适。

## 裁剪

1. 点击**裁剪**，拖入一张图片。
2. 拖动裁剪框的角部和边缘控制点，或选一个固定纵横比——**自由**和**原图**始终可选，旁边还有常用的固定比例。
3. 拖动时悬浮角标实时显示数字：原始尺寸（“原图 4032 × 3024 px”）和选中比例（“占 42%”），让你按数字取景，而不是靠目测。
4. 按**保存**（⌘S）。

### 选项

- **纵横比** — **自由**随意裁；**原图**保持原始比例；固定比例适合封面、头像和缩略图。
- **对齐方式**（流水线步骤） — 批量裁剪相对锚点进行：**居中**、**左上**、**右上**、**左下**、**右下**。

## 图片旋转

1. 点击**图片旋转**，拖入图片。
2. 常见的直角旋转用**左转 90°** / **右转 90°**；水平或垂直镜像用翻转按钮；任意角度则拖动角度控件——标签实时读出当前值（“角度: 12°”）。
3. 任意角度旋转会扩大画布以容纳旋转后的图像；预览会在保存前显示旋转后的外接矩形及其像素尺寸。
4. 按**保存**（⌘S）。

## 提示与限制

- **调整大小不会凭空造出细节。** 用它放大只是像素插值。想放大照片并补出可信的细节，请用 [AI 超分](../ai/ai-upscale.md)。
- **流水线里顺序很重要。** 把**裁剪**和**缩放**放在**水印**之前——如果水印步骤排在它们前面，应用会警告：水印可能被裁掉或变模糊。
- **不确定就锁上纵横比。** 解锁状态下随意输入宽 × 高会拉伸图片。锁链图标一眼就能看出当前状态。
- **有损格式按 95% 质量保存。** 调整大小、裁剪和图片旋转导出 JPEG、HEIC 等有损格式时固定使用 95% 质量，不受设置中默认质量的影响。

## 疑难解答

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 缩放后的图片变形了 | **锁定纵横比**是关闭的，宽高两个值都被改过 | 打开锁定，重新输入其中一个尺寸 |
| 放大后的图片发虚 | 调整大小是插值运算，补不出细节 | 放大请用 [AI 超分](../ai/ai-upscale.md) |
| 旋转后的图片多出空白区域 | 任意角度旋转会扩大画布来容纳旋转后的画面 | 属正常现象——想要紧凑画面可以在旋转后再裁剪 |
| 还是解决不了 | — | [提交 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
