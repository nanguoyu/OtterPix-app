# PDF 转图片与二维码生成

两个小而精的实用工具：**PDF 转图片**按你选定的分辨率把 PDF 页面渲染成图片文件，**二维码生成**从文本或链接生成二维码。

## PDF 转图片

### 一览

| | |
|---|---|
| **可用性** | 免费 |
| **运行方式** | 在你的 Mac 上——离线运行，不上传任何内容 |
| **输入** | 一个 PDF（“选择或拖拽 PDF 文件到此处”；⌘V 粘贴也行） |
| **输出** | 每页一个图片文件，保存到你选择的位置 |
| **流水线步骤** | 无 |

### 如何转换 PDF 页面

1. 点击 **PDF 转图片**，拖入一个 PDF。工具会显示页数（“12 页 PDF”）并提供逐页预览。
2. 选择要转换的页面：全部（“全部 12 页”），或**页面范围**配合**起始** / **结束**——页码可以直接键入，也可以用步进按钮微调。
3. 设置**分辨率 (DPI)**。DPI 越高，图片越大越清晰——屏幕上看选适中的值就够；打印或放大细读就调高。
4. 选输出格式——文字和图形要锐利选 PNG，照片型页面想更小选 JPEG。
5. 点击**转换并保存第 3 页**（单页）或**转换并保存 12 页**（范围），选择保存位置。**选择其他 PDF 文件**可直接换文档，无需离开工具。

### 提示与限制

- **PDF 可以按任意 DPI 渲染** ——源文件在可能之处是矢量的，所以调高 DPI 得到的是真实的清晰度提升，不是简单放大像素。
- **每页一个文件。** 范围导出写出按序编号的图片，直接可用于幻灯片或网页嵌入。
- **从扫描版 PDF 里提取*文字*是另一件事** ——那是 [AI 文字识别](../ai/ai-ocr.md)的活，它把文档和扫描件转成 Markdown。

## 二维码生成

### 一览

| | |
|---|---|
| **可用性** | 免费 |
| **运行方式** | 在你的 Mac 上——离线运行，不上传任何内容 |
| **输入** | 文本或链接 |
| **输出** | 二维码图片，保存到你选择的位置 |
| **流水线步骤** | 无 |

### 如何生成二维码

1. 点击**二维码生成**。
2. 在内容栏输入或粘贴（“输入二维码内容”）——网址、Wi-Fi 信息、联系方式、任何文本。预览随输入实时重新生成。
3. 设置**大小**——像素值可以直接键入，也可以用步进按钮微调。
4. 选择**纠错级别**。级别越高，二维码在部分遮挡或印得很小时仍能扫出，但图案会更密。
5. 需要的话调整**前景色**和**背景色**。
6. 按**保存**（⌘S）。

### 提示与限制

- **保持高对比度。** 深色前景配浅色背景扫描最可靠；花哨的配色可能让扫码器失灵。
- **内容长就要留余量。** 看到“内容过长，超出该纠错级别的容量。”时，缩短文本或调低纠错级别——纠错越强，容量越小。
- **批量印刷前先试印一张。** 扫码表现随印刷尺寸和介质变化，用手机花十秒试扫一下，省得整批重印。

## 疑难解答

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 导出的 PDF 页面发虚 | DPI 相对目标尺寸太低 | 调高**分辨率 (DPI)** 重新导出 |
| “内容过长，超出该纠错级别的容量。” | 当前设置下超出二维码容量 | 缩短内容，或选择更低的**纠错级别** |
| 手机扫不出生成的码 | 颜色对比度低，或印得太小 | 恢复深色配浅色，调大**大小**，提高纠错级别 |
| 还是解决不了 | — | [提交 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
