# PDF 轉圖片與 QR Code 產生器

兩個小而精準的公用工具：**PDF 轉圖片**以你指定的解析度把 PDF 頁面輸出為圖片檔，**QR Code 產生器**從文字或連結生成 QR Code。

## PDF 轉圖片

### 一覽

| | |
|---|---|
| **取得方式** | 免費 |
| **執行位置** | 你的 Mac——離線執行，不上傳任何內容 |
| **輸入** | 一個 PDF（「選擇或拖曳 PDF 檔案到此處」；⌘V 貼上也可以） |
| **輸出** | 每頁一個圖片檔，存到你選擇的位置 |
| **流程步驟** | 無 |

### 如何轉換 PDF 頁面

1. 點選 **PDF 轉圖片**，拖入一個 PDF。工具會顯示頁數（「12 頁 PDF」）與逐頁預覽。
2. 選擇要轉換的頁面：全部（「全部 12 頁」），或用**頁面範圍**設定**起始** / **結束**——直接輸入頁碼，或用步進器微調。
3. 設定**解析度 (DPI)**。DPI 越高，輸出的圖片越大、越銳利——螢幕閱讀用適中的數值就夠；列印或放大細讀就往上調。
4. 選擇輸出格式——文字與圖形選 PNG 最銳利，照片為主的頁面用 JPEG 比較小。
5. 點選**轉換並儲存第 3 頁**（單頁）或**轉換並儲存 12 頁**（範圍），選擇儲存位置。**選擇其他 PDF 檔案**可在不離開工具的情況下換文件。

### 秘訣與限制

- **PDF 可以用任意 DPI 算繪**——來源在可能之處是向量的，所以提高 DPI 是真正增加銳利度，而不只是放大像素。
- **每頁一個檔案。** 範圍輸出會寫出帶編號的圖片，直接可用於簡報或網頁嵌入。
- **從掃描 PDF 抽取*文字*是另一件事**——那是 [AI 文字辨識](../ai/ai-ocr.md)的工作，它能把文件與掃描檔轉成 Markdown。

## QR Code 產生器

### 一覽

| | |
|---|---|
| **取得方式** | 免費 |
| **執行位置** | 你的 Mac——離線執行，不上傳任何內容 |
| **輸入** | 文字或連結 |
| **輸出** | 一張 QR Code 圖片，存到你選擇的位置 |
| **流程步驟** | 無 |

### 如何產生 QR Code

1. 點選 **QR Code 產生器**。
2. 在內容欄位輸入或貼上（「輸入QR Code內容」）——網址、Wi-Fi 資訊、聯絡資料，任何文字都行。預覽隨打字即時重新生成。
3. 設定**大小**——直接輸入精確的像素值，或用步進器微調。
4. 選擇**錯誤修正等級**。等級越高，QR Code 被部分遮蓋或印得很小時仍能掃描，代價是圖樣更密。
5. 需要時調整**前景色**與**背景色**。
6. 按**儲存**（⌘S）。

### 秘訣與限制

- **保持高對比。** 深色前景配淺色背景掃描最可靠；花俏的配色可能讓掃描器失手。
- **內容長就要留餘裕。** 若看到「內容過長，超出該糾錯等級的容量。」，就縮短文字或調低錯誤修正等級——修正力越強，容量越小。
- **大量印刷前先試印一張。** 掃描表現會隨印刷尺寸與材質變化；花十秒用手機測一下，能省下一次重印。

## 疑難排解

| 你看到的 | 原因 | 解法 |
|---|---|---|
| 輸出的 PDF 頁面看起來糊糊的 | DPI 相對目標尺寸太低 | 調高**解析度 (DPI)** 重新輸出 |
| 「內容過長，超出該糾錯等級的容量。」 | 目前設定下超過 QR Code 容量 | 縮短內容，或選較低的**錯誤修正等級** |
| 手機掃不出產生的 QR Code | 對比不足，或印得太小 | 換回深色配淺色、加大**大小**、調高錯誤修正等級 |
| 還是卡住 | — | [開一個 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
