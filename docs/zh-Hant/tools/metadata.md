# 後設資料

**後設資料**——App Store 介紹頁上稱為「EXIF 檢視器」——負責讀取、編輯與清除照片裡看不見的資料：EXIF 相機參數、GPS 座標、IPTC 創作者欄位與檔案細節。它最常見的任務只需一個開關：在照片離開你的 Mac 之前移除 GPS 位置。

## 一覽

| | |
|---|---|
| **取得方式** | 免費 |
| **執行位置** | 你的 Mac——離線執行，不上傳任何內容 |
| **輸入** | 單張或多張圖片（多張時會出現縮圖列） |
| **輸出** | 清理／編輯後的副本存到你選擇的位置；原始檔案保持原樣 |
| **流程步驟** | **清除後設資料**——見[處理流程](../pipeline.md) |

## 三種模式

工具頂部有三種模式：**檢視**、**編輯**、**清除**。

### 檢視

檔案攜帶的一切，分門別類整齊呈現：相機（**製造商**、**型號**、**鏡頭**）、EXIF 曝光資料（**光圈**、**快門**、**ISO**、**焦距**、**拍攝日期**）、GPS（**緯度**、**經度**、**海拔**）、IPTC（**創作者**、**出處**、**說明**、**版權**）與檔案細節（**尺寸**、**色彩模型**、**方向**、**軟體**）。

### 編輯

逐欄改寫個別欄位——**作者**、**版權**、**描述**、**拍攝日期**——或撥動**移除 GPS** 開關，只去掉位置資訊，相機、日期與曝光欄位保持不動。用**儲存修改…**（⌘S）送出。

### 清除

透過**預設**選項整批抹除後設資料，然後按**清除並另存為…**：

- **隱私**——「清除 GPS、相機型號、鏡頭、創作者。保留拍攝日期、曝光資料、方向。」它還會移除相機擁有者姓名與鏡頭序號，以及 IPTC 中的創作者、聯絡資訊、版權與地點欄位。分享前的合理預設：照片仍能按日期正確排序、以正確方向顯示，但不再透露拍攝地點、使用的器材與拍攝者。
- **全部**——「清除所有後設資料欄位。僅保留畫素資料。」

## 如何在分享前移除 GPS

1. 點選側邊欄的**全部功能**，再點**後設資料**。
2. 拖入一張或多張照片——多檔時底部會出現縮圖列，方便逐張切換。
3. 先在**檢視**模式看看檔案裡到底有什麼。
4. 只要去掉位置：切到**編輯**，撥動**移除 GPS**，按**儲存修改…**（⌘S）。
5. 想清得更徹底：切到**清除**，選**隱私**或**全部**預設，按**清除並另存為…**。
6. 選擇清理後的副本要存到哪裡。你的原始檔案在磁碟上保持原樣。

## 為什麼要清除後設資料

照片的 EXIF 可能包含拍攝地點的精確 GPS 座標——發布前值得主動移除，因為電子郵件、雲端硬碟與直接上傳檔案通常會原封不動地把原始檔傳出去。

## 秘訣與限制

- **清除後設資料不會改變畫面。** 這項操作針對的是隱藏的紀錄，不是看得見的畫面；JPEG 等失真壓縮格式會以高品質重新編碼。清理後的版本會另存為新副本，隨時可以兩相對照。
- **整個資料夾：** 在[處理流程](../pipeline.md)裡加一個**清除後設資料**步驟，一趟清完一個資料夾——想同時縮放、加浮水印也沒問題。
- **別指望平台幫你清。** 許多社群平台會重新處理上傳的圖片並丟棄大部分後設資料，但細節因服務而異、也會隨時間改變。如果移除很重要，就讓它成為一個明確的步驟。

## 疑難排解

| 你看到的 | 原因 | 解法 |
|---|---|---|
| 檢視模式裡 GPS 區塊是空的 | 照片本來就沒有位置資料（或早已被清除） | 沒有東西可移除——你已經完成了 |
| 編輯的欄位沒有生效 | 修改在儲存時寫入，不是即時寫入 | 按**儲存修改…**（⌘S），然後檢查儲存的副本 |
| 清除後照片沒辦法按日期排序了 | **全部**預設把拍攝日期也移除了 | 改用**隱私**預設——它保留日期、曝光與方向 |
| 還是卡住 | — | [開一個 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
