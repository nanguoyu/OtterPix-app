# 調整大小、裁切與圖片旋轉

幾何三件組：**調整大小**按百分比或精確尺寸縮放圖片，**裁切**以自由或固定長寬比修邊，**圖片旋轉**做任意角度的旋轉與翻轉。三者皆免費，也都有對應的[處理流程](../pipeline.md)步驟可供批次使用。

## 一覽

| | |
|---|---|
| **取得方式** | 免費 |
| **執行位置** | 你的 Mac——離線執行，不上傳任何內容 |
| **輸入** | 單張圖片或整批 |
| **輸出** | 處理後的副本，存到你選擇的位置 |
| **流程步驟** | **縮放**、**裁切**、**旋轉**——見[處理流程](../pipeline.md) |

## 調整大小

1. 點選**調整大小**，拖入你的圖片。
2. 選擇縮放方式：按百分比，或在**寬度**與**高度**欄位輸入精確的像素值。可以直接輸入數字，也可以用步進器微調。
3. 兩個欄位之間的鏈條圖示切換**鎖定縱橫比**——鎖定時，改動一個欄位會自動換算另一個；解鎖時兩者各自獨立（圖片可能因此變形）。
4. 按**儲存**（⌘S）。

### 選項

- **百分比**——快速的等比縮放，例如網頁用途縮到 50%。
- **精確尺寸**——以像素輸入**寬度** / **高度**，**鎖定縱橫比**預設開啟。
- **限定在**——適合批次的「限制框」模式。用 App 自己的話說：「每張圖按自身比例縮放以適應此框；已小於該尺寸的圖保持不變。」當一個資料夾裡直式橫式混雜、又要求全部不超過例如 1920 px 時，最合適。

## 裁切

1. 點選**裁切**，拖入一張圖片。
2. 拖動裁切框的四角與邊緣控制點，或選一個固定長寬比——**自由**與**原圖**永遠可選，旁邊還有常見的固定比例。
3. 拖動時，浮動徽章會以數字顯示目前的裁切狀態：原始尺寸（「原圖 4032 × 3024 px」）與選取比例（「佔 42%」），讓你精準取景而不是用目測。
4. 按**儲存**（⌘S）。

### 選項

- **長寬比**——**自由**可任意裁切；**原圖**保持來源比例；固定比例適合封面、頭像與縮圖。
- **對齊方式**（流程步驟）——批次裁切步驟以錨點為基準裁切：**置中**、**左上**、**右上**、**左下**、**右下**。

## 圖片旋轉

1. 點選**圖片旋轉**，拖入你的圖片。
2. 常見的直角旋轉用**左轉 90°** / **右轉 90°**；水平或垂直鏡像用翻轉按鈕；自由角度則拖動角度控制——標籤會即時讀出目前數值（「角度: 12°」）。
3. 自由角度會放大畫布以容納旋轉後的圖片；儲存前，預覽會先顯示旋轉後的外框及其像素尺寸。
4. 按**儲存**（⌘S）。

## 秘訣與限制

- **調整大小無法憑空生出細節。** 用調整大小*放大*只是像素插值。想放大照片並補回可信的細節，請改用 [AI 超分](../ai/ai-upscale.md)。
- **流程中的順序有影響。** 把**裁切**和**縮放**排在**浮水印**之前——若浮水印步驟排在它們前面，App 會提出警告，因為浮水印可能被裁掉或變模糊。
- **不是有意變形就把比例鎖上。** 解鎖狀態下輸入任意的寬度 × 高度會拉伸圖片。鏈條圖示讓你一眼看出目前狀態。

## 疑難排解

| 你看到的 | 原因 | 解法 |
|---|---|---|
| 縮放後的圖片變形了 | **鎖定縱橫比**是關閉的，而且兩個欄位都被改過 | 打開鎖定，重新輸入其中一個尺寸 |
| 放大後的圖片變得鬆軟 | 調整大小只做插值，無法補細節 | 放大請用 [AI 超分](../ai/ai-upscale.md) |
| 旋轉後的圖片多出空白區域 | 自由角度旋轉會放大畫布以容納旋轉後的畫面 | 屬正常行為——想要緊湊的畫面就在之後再裁切 |
| 還是卡住 | — | [開一個 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
