# 批次重新命名

**批次重新命名**用範本系統一次替大量圖片檔案改名——流水序號、EXIF 拍攝日期、相機名稱——並在寫入任何檔案之前顯示完整預覽。

## 一覽

| | |
|---|---|
| **取得方式** | 免費 |
| **執行位置** | 你的 Mac——離線執行，不上傳任何內容 |
| **輸入** | 任意數量的圖片檔案 |
| **輸出** | 改名後的副本存到你選擇的資料夾；除非你主動選擇丟進垃圾桶，原始檔案留在原位 |
| **流程步驟** | 無——重新命名是獨立工具 |

## 如何批次重新命名

1. 點選**批次重新命名**，把檔案拖進來，或用**新增檔案…**。
2. 用**排序**決定順序——**檔名**、**EXIF 日期**或**修改日期**。順序決定序號的先後。
3. 在**範本**欄位組出命名模式。欄位下方是 token 晶片——「點選插入 token」。預設範本是 `{name}_{counter:03}.{ext}`。
4. 盯著**預覽**欄：每個檔案的新名字即時顯示，衝突會在你送出之前先被標記出來（「2 處衝突」）。
5. 需要時再用**尋找與取代**和**大小寫**微調（見選項）。
6. 按**儲存**（⌘S），然後**選擇資料夾**。如 App 所述：「選擇 OtterPix 把重新命名後的檔案儲存到哪裡。除非勾選了『將原檔案移到垃圾桶』，否則原檔案會保留在原位置。」

## 範本 token

| Token | 產生什麼 |
|---|---|
| `{name}` | 原始檔名，不含副檔名 |
| `{ext}` | 原始副檔名（`jpg`、`png`、…） |
| `{counter}` | 流水序號；**序號起點**與**步長**皆可設定 |
| `{counter:03}` | 補零到指定寬度的序號——`001`、`002`、… |
| `{date}` | EXIF 拍攝日期（照片沒有時退回檔案的修改日期） |
| `{date:yyyy-MM-dd}` | 自訂格式的拍攝日期 |
| `{mdate}` | 檔案的修改日期；同樣支援自訂格式 |
| `{exif:camera}` | EXIF 中的相機製造商與型號 |

範例：`{date:yyyy-MM-dd}_{exif:camera}_{counter:03}.{ext}` → `2026-05-14_Apple iPhone 15 Pro_001.heic`。

## 選項

### 尋找與取代

一組在範本之後套用的**尋找** / **取代為**欄位，並附**正規表示式**開關，可做模式化修改——去掉前綴、換分隔符、收合空格。

### 大小寫

統一最終檔名的大小寫：**保持**、**全小寫**、**全大寫**或**首字母大寫**。

### 將原檔案移到垃圾桶

預設關閉。開啟時，會在所有檔案都存進指定資料夾*之後*，把原始檔案移到 macOS 垃圾桶——需要時可從垃圾桶救回。這是這個工具最接近「原地改名」的方式；預設情況下它從不碰你的來源檔案。

## 秘訣與限制

- **預覽就是合約。** 在你儲存之前不會寫入任何東西；衝突（兩個檔案算出同一個名字，或目標名字已存在於磁碟上）會先在預覽裡浮現。
- **`{date}` 需要 EXIF。** 螢幕截圖與匯出的圖形常常沒有拍攝日期，此時 `{date}` 會退回檔案的修改日期。按 **EXIF 日期**排序只對相機照片有意義。
- **剪貼簿裡的圖片無法改名。** 貼上需要真實檔案：「剪貼簿裡是圖片資料而不是檔案——請先儲存為檔案再新增。」

## 疑難排解

| 你看到的 | 原因 | 解法 |
|---|---|---|
| 預覽顯示「2 處衝突」 | 兩個輸入算出相同名字，或目標名字已存在 | 在範本中加入 `{counter}`，或調整模式直到預覽無衝突 |
| `{date}` 給出今天的日期，而不是拍照日期 | 檔案沒有 EXIF 拍攝日期 | 屬預期的修改日期退回——用[後設資料](metadata.md)工具檢查該檔案的欄位 |
| 檔案存好了，但原始檔還在 | 預設行為——除非主動勾選，原始檔案永不移除 | 想要的話就開啟**將原檔案移到垃圾桶** |
| 還是卡住 | — | [開一個 Issue](https://github.com/nanguoyu/OtterPix-app/issues/new/choose) |
